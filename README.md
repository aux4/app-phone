# aux4/app-phone

Authenticated audio calling for aux4 users and Chat channels. The package uses the platform's SSO principal and a local, loopback-only WebRTC signaling provider. Media stays peer-to-peer between browsers; the provider exchanges offers, answers, and ICE candidates.
